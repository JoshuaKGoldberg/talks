## Usage

Building needs slidev2pptx, which isn't published yet, checked out and built next to this repository in `../slidev2pptx`; see [`.github/DEVELOPMENT.md`](./.github/DEVELOPMENT.md).
Presenting a talk with Slidev doesn't.

```shell
pnpm build
```

...builds every talk into a PowerPoint file in its package's `lib/` directory.
To build or present one talk, run its package's `build` or `dev` script:

```shell
pnpm --filter 2026-05-21-what-s-new-in-typescript-6-0 build
pnpm --filter 2026-05-21-what-s-new-in-typescript-6-0 dev
```
