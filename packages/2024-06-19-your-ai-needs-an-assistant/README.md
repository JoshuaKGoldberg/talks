# Your AI Needs an Assistant

Slides for Your AI Needs an Assistant, a talk given at:

- [CascadiaJS 2024](https://cascadiajs.com/2024), Seattle, USA: June 19, 2024 ([video](https://www.youtube.com/watch?v=Qlbef5hzDYQ))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucjqgr5yDYgg0UeLA), so they may look a little different.

## Usage

To build the deck into `lib/2024-06-19-your-ai-needs-an-assistant.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
