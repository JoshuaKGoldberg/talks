# Your AI Needs an Assistant

Slides for Your AI Needs an Assistant, a talk given at:

- [CascadiaJS 2024](https://cascadiajs.com/2024), Seattle, USA: June 19, 2024 ([video](https://www.youtube.com/watch?v=Qlbef5hzDYQ))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucjqgr5yDYgg0UeLA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-06-19-your-ai-needs-an-assistant.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
