# GraphQL + Apollo + Next.js: A Lovely Trio

Slides for GraphQL + Apollo + Next.js: A Lovely Trio, a talk given at:

- [WeAreDevelopers JS Congress 2021](https://www.wearedevelopers.com): November 23, 2021 ([client](https://github.com/JoshuaKGoldberg/a-lovely-trio), [server](https://github.com/JoshuaKGoldberg/a-lovely-graphql-server))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtI2Ha9qbYakUWSBUg?e=E7N6p3), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-11-23-graphql-apollo-next-js-a-lovely-trio.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
