# GraphQL + Apollo + Next.js: A Lovely Trio

Slides for GraphQL + Apollo + Next.js: A Lovely Trio, a talk given at:

- [WeAreDevelopers JS Congress 2021](https://www.wearedevelopers.com): November 23, 2021 ([client](https://github.com/JoshuaKGoldberg/a-lovely-trio), [server](https://github.com/JoshuaKGoldberg/a-lovely-graphql-server))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtI2Ha9qbYakUWSBUg?e=E7N6p3), so they may look a little different.

## Usage

To build the deck into `lib/2021-11-23-graphql-apollo-next-js-a-lovely-trio.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
