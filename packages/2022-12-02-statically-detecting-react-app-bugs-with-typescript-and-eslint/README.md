# Statically Detecting React App Bugs with TypeScript and ESLint

Slides for Statically Detecting React App Bugs with TypeScript and ESLint, a talk given at:

- [React Day Berlin 2022](https://reactday.berlin/2022): December 2, 2022 ([video](https://portal.gitnation.org/contents/statically-detecting-react-app-bugs-with-typescript-and-eslint))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRJt4bkrcKsMarwqg?e=ozt3AY), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-12-02-statically-detecting-react-app-bugs-with-typescript-and-eslint.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
