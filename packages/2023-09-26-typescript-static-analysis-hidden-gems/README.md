# TypeScript Static Analysis Hidden Gems

Slides for TypeScript Static Analysis Hidden Gems, a talk given at:

- JSDay IE 2023, Dublin, Ireland: September 26, 2023 ([video](https://www.youtube.com/watch?v=qxAwVwgEmZU))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMWM4OEEUB2khjYjA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
