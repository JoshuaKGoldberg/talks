# TypeScript Static Analysis Hidden Gems

Slides for TypeScript Static Analysis Hidden Gems, a talk given at:

- [JSDay IE 2023](https://www.jsday.ie), Dublin, Ireland: September 26, 2023 ([video](https://www.youtube.com/watch?v=qxAwVwgEmZU))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMWM4OEEUB2khjYjA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-09-26-typescript-static-analysis-hidden-gems.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
