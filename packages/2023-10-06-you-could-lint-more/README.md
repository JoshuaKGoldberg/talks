# You Could Lint More

Slides for You Could Lint More, a talk given at:

- [revo.js 2023](https://revojs.ro/2023), Timișoara, Romania: October 6, 2023 ([video](https://www.youtube.com/watch?v=voYSdj3Xqvc&t=1s&ab_channel=tim.js))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMeYEDLI5BZo-gJjw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
