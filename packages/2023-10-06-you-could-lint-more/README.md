# You Could Lint More

Slides for You Could Lint More, a talk given at:

- [revo.js 2023](https://revojs.ro/2023), Timișoara, Romania: October 6, 2023 ([video](https://www.youtube.com/watch?v=voYSdj3Xqvc&t=1s&ab_channel=tim.js))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMeYEDLI5BZo-gJjw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-10-06-you-could-lint-more.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
