# WebXR Karaoke

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2022-07-01-webxr-karaoke.pptx)**

Slides for WebXR Karaoke, a talk given at:

- [HalfStack Newquay 2022](https://halfstackconf.com/newquay/2022), Newquay, England: July 1, 2022 ([repo](https://github.com/karaokenite/karaokenite-react))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQ8tOAxwVUF_gTUPg?e=X0uUHn), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
