# WebXR Karaoke

Slides for WebXR Karaoke, a talk given at:

- [HalfStack Newquay 2022](https://halfstackconf.com/newquay/2022), Newquay, England: July 1, 2022 ([repo](https://github.com/karaokenite/karaokenite-react))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQ8tOAxwVUF_gTUPg?e=X0uUHn), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-07-01-webxr-karaoke.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
