Slides for Static Analysis: Shockingly Awesome! ⚡️, a talk given at:

- [JSConf JP 2023](https://jsconf.jp/2023/talk/josh-goldberg-1), Online: November 19, 2023 ([video](https://www.youtube.com/watch?v=9ZBkN1ciLrU&ab_channel=jsconfjp))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQ-Z78lXiYl5UVQEA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
