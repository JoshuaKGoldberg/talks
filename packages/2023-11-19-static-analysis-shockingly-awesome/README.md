# Static Analysis: Shockingly Awesome! ⚡️

Slides for Static Analysis: Shockingly Awesome! ⚡️, a talk given at:

- [JSConf JP 2023](https://jsconf.jp/2023/talk/josh-goldberg-1), Online: November 19, 2023 ([video](https://www.youtube.com/watch?v=9ZBkN1ciLrU&ab_channel=jsconfjp))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQ-Z78lXiYl5UVQEA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-11-19-static-analysis-shockingly-awesome.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
