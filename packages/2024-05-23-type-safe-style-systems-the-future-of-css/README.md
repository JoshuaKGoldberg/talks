# Type-Safe Style Systems: The Future of CSS

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [JSHeroes](https://jsheroes.io), Cluj-Napoca, Romania: May 23, 2024 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://www.youtube.com/watch?v=8c5BIaKkHj4&ab_channel=JSHeroes))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucokO5vNfGARtHveQ), so they may look a little different.

## Usage

To build the deck into `lib/2024-05-23-type-safe-style-systems-the-future-of-css.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
