# Type-Safe Style Systems: The Future of CSS

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [JSHeroes](https://jsheroes.io), Cluj-Napoca, Romania: May 23, 2024 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://www.youtube.com/watch?v=8c5BIaKkHj4&ab_channel=JSHeroes))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucokO5vNfGARtHveQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-05-23-type-safe-style-systems-the-future-of-css.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
