# Enums are MISUNDERSTOOD (Not Terrible)

Slides for Enums are MISUNDERSTOOD (Not Terrible), a talk given at:

- [Michigan TypeScript](https://www.meetup.com/michigan-typescript-developers/events/291207877), Ann Arbor, Michigan, USA: March 7, 2023 ([video](https://www.youtube.com/watch?v=XTXPKbPcvl4&ab_channel=MichiganTypeScript))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtxotadetl0OqRwitA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-03-07-enums-are-misunderstood-not-terrible.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
