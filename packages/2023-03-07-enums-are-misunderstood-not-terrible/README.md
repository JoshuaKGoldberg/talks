# Enums are MISUNDERSTOOD (Not Terrible)

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2023-03-07-enums-are-misunderstood-not-terrible.pptx)**

Slides for Enums are MISUNDERSTOOD (Not Terrible), a talk given at:

- [Michigan TypeScript](https://www.meetup.com/michigan-typescript-developers/events/291207877), Ann Arbor, Michigan, USA: March 7, 2023 ([video](https://www.youtube.com/watch?v=XTXPKbPcvl4&ab_channel=MichiganTypeScript))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtxotadetl0OqRwitA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
