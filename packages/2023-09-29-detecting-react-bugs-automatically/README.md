# Detecting React Bugs Automatically

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/raw/main/2023-09-29-detecting-react-bugs-automatically.pptx)**

Slides for Detecting React Bugs Automatically, a talk given at:

- [React Live 2023](https://reactlive.nl), Amsterdam, NL: September 29, 2023 ([video](https://www.youtube.com/watch?v=zBN7aHDRsZw))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMaI_-L-BkT9QQRYA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
