# Detecting React Bugs Automatically

Slides for Detecting React Bugs Automatically, a talk given at:

- [React Live 2023](https://reactlive.nl), Amsterdam, NL: September 29, 2023 ([video](https://www.youtube.com/watch?v=zBN7aHDRsZw))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMaI_-L-BkT9QQRYA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-09-29-detecting-react-bugs-automatically.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
