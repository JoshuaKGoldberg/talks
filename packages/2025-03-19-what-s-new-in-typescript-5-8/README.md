# What's New in TypeScript 5.8

Slides for What's New in TypeScript 5.8, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-ts-club-spring-typing-tickets-1249401757289), Boston, USA: March 19, 2025

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EewQYfBZaf1GvwkzonnYf74BoDCBtLM3GFqsqz5GT40y2w), so they may look a little different.

## Usage

To build the deck into `lib/2025-03-19-what-s-new-in-typescript-5-8.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
