# What's New in TypeScript 5.8

Slides for What's New in TypeScript 5.8, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-ts-club-spring-typing-tickets-1249401757289), Boston, USA: March 19, 2025

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EewQYfBZaf1GvwkzonnYf74BoDCBtLM3GFqsqz5GT40y2w), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2025-03-19-what-s-new-in-typescript-5-8.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
