# Building a Design System Mid-Flight

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2023-10-13-building-a-design-system-mid-flight.pptx)**

Slides for Building a Design System Mid-Flight, a talk given at:

- LibertyJS 2023, Philadelphia, Pennsylvania: October 13, 2023

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMgsCt8tMkQgna1MA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
