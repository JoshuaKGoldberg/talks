# Building a Design System Mid-Flight

Slides for Building a Design System Mid-Flight, a talk given at:

- LibertyJS 2023, Philadelphia, Pennsylvania: October 13, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMgsCt8tMkQgna1MA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-10-13-building-a-design-system-mid-flight.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
