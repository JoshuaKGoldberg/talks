# Static Analysis: Don't Fear the Linter!

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2023-08-08-static-analysis-don-t-fear-the-linter.pptx)**

Slides for Static Analysis: Don't Fear the Linter!, a talk given at:

- [SeattleJS Conf 2023](https://seattlejs.com/talks/dont-fear-the-linter), Seattle, USA: August 8, 2023 ([video](https://www.youtube.com/watch?v=qiDzxvdKt-Y))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuE5LELJVy5LuVm9Kw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
