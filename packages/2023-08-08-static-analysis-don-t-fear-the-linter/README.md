# Static Analysis: Don't Fear the Linter!

Slides for Static Analysis: Don't Fear the Linter!, a talk given at:

- [SeattleJS Conf 2023](https://seattlejs.com/talks/dont-fear-the-linter), Seattle, USA: August 8, 2023 ([video](https://www.youtube.com/watch?v=qiDzxvdKt-Y))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuE5LELJVy5LuVm9Kw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-08-08-static-analysis-don-t-fear-the-linter.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
