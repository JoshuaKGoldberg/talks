> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucPTe-lyqMnWVKdVg), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
