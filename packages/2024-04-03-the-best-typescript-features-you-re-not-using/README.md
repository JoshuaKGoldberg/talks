# The Best TypeScript Features You're Not Using

Slides for The Best TypeScript Features You're Not Using, a talk given at:

- CityJS London 2024, London, UK: April 3, 2024 ([video](https://www.youtube.com/watch?v=0PqDDYSaz2Y))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucPTe-lyqMnWVKdVg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-04-03-the-best-typescript-features-you-re-not-using.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
