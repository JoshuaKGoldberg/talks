# The Best TypeScript Features You're Not Using

Slides for The Best TypeScript Features You're Not Using, a talk given at:

- CityJS London 2024, London, UK: April 3, 2024 ([video](https://www.youtube.com/watch?v=0PqDDYSaz2Y))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucPTe-lyqMnWVKdVg), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
