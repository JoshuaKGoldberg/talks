# Focus Visible, At Last!

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2022-04-01-focus-visible-at-last.pptx)**

Slides for Focus Visible, At Last!, a talk given at:

- [Web Directions Hover 2022](https://webdirections.org/hover/speakers/josh-goldberg.php), Online: April 1, 2022 ([video](https://conffab.com/video/focus-visible-at-last))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMMTmSteM_0OP3ywg?e=wYvucy), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
