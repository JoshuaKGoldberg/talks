# Breaking the Codecademy Course Catalog

Slides for Breaking the Codecademy Course Catalog, a talk given at:

- [React JS Case Study Festival 2021](https://events.geekle.us): April 27, 2021 ([video](https://youtu.be/HVoPNeLqM8I?t=33274))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtE4dyMr1VL3UtWyjw?e=BwUZvh), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-04-27-breaking-the-codecademy-course-catalog.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
