# Breaking the Codecademy Course Catalog

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2021-04-27-breaking-the-codecademy-course-catalog.pptx)**

Slides for Breaking the Codecademy Course Catalog, a talk given at:

- React JS Case Study Festival 2021: April 27, 2021 ([video](https://youtu.be/HVoPNeLqM8I?t=33274))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtE4dyMr1VL3UtWyjw?e=BwUZvh), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
