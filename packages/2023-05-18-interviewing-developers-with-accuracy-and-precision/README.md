Slides for Interviewing Developers with Accuracy and Precision, a talk given at:

- [JSConf India 2023](https://jsconf.in), Online: May 18, 2023 ([video](https://www.youtube.com/watch?v=eY2lmQ8o3EI&t=10125s&ab_channel=JSConf))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt4kuQ5uqsWwXVu8MQ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
