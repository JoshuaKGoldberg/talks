# Static Analysis: Shockingly Useful! ⚡️

Slides for Static Analysis: Shockingly Useful! ⚡️, a talk given at:

- [Web Directions Code 2023](https://webdirections.org/code), Melbourne, Australia: June 9, 2023 ([video](https://conffab.com/presentation/static-analysis-shockingly-useful-%e2%9a%a1%ef%b8%8f))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt8B6-y28tCUw7Xqmg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-06-09-static-analysis-shockingly-useful.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
