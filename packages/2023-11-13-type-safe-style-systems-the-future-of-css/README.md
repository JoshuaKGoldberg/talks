# Type-Safe Style Systems: The Future of CSS

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2023-11-13-type-safe-style-systems-the-future-of-css.pptx)**

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [React Summit 2023](https://reactsummit.us), New York City, New York USA: November 13, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://portal.gitnation.org/contents/type-safe-style-systems-the-future-of-css))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMi-FLvoFlHme1QPg), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
