# Type-Safe Style Systems: The Future of CSS

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [React Summit 2023](https://reactsummit.us), New York City, New York USA: November 13, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://portal.gitnation.org/contents/type-safe-style-systems-the-future-of-css))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMi-FLvoFlHme1QPg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-11-13-type-safe-style-systems-the-future-of-css.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
