# Building a Design System as a Team

Slides for Building a Design System as a Team, a talk given at:

- [JSWorld USA 2021](https://usa.jsworldconference.com), Online: May 21, 2021 ([video](https://jsworldconference.com/video/jsworld-conference-usa))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFVKVjyXpUGIs9HwA?e=Jvoj9I), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
