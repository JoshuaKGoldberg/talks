# TypeScript for JavaScripties

Slides for TypeScript for JavaScripties, a workshop given at:

- [SeattleJS Conf 2023](https://seattlejs.com/conf), Seattle, WA: August 9, 2023

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuE7lr9l-Z24Y1Z9Kw), so they may look a little different.

## Usage

To build the deck into `lib/2023-08-09-typescript-for-javascripties.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
