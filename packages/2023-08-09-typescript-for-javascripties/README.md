# TypeScript for JavaScripties

Slides for TypeScript for JavaScripties, a workshop given at:

- [SeattleJS Conf 2023](https://seattlejs.com/conf), Seattle, WA: August 9, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuE7lr9l-Z24Y1Z9Kw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-08-09-typescript-for-javascripties.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
