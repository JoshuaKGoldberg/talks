# Lessons Learned from Refactors and Rearchitectures

Slides for Lessons Learned from Refactors and Rearchitectures, a talk given at:

- [LeadDev Berlin 2022](https://leaddev.com/leaddev-berlin/agenda), Berlin, Germany: November 3, 2022

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRBZoYOVyAnuPeClQ), so they may look a little different.

## Usage

To build the deck into `lib/2022-11-03-lessons-learned-from-refactors-and-rearchitectures.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
