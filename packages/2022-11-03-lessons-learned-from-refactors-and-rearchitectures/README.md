# Lessons Learned from Refactors and Rearchitectures

Slides for Lessons Learned from Refactors and Rearchitectures, a talk given at:

- [LeadDev Berlin 2022](https://leaddev.com/leaddev-berlin/agenda), Berlin, Germany: November 3, 2022 ([video](https://leaddev.com/leaddev-berlin/videos))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRBZoYOVyAnuPeClQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-11-03-lessons-learned-from-refactors-and-rearchitectures.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
