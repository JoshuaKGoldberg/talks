# The Best TypeScript Features You Might Not Be Using

Slides for The Best TypeScript Features You Might Not Be Using, a talk given at:

- [Emerging Tech East 2024](https://emergingtecheast.com), Philadelphia, USA: April 9, 2024 ([video](https://www.youtube.com/watch?v=laT7uigly54&ab_channel=ChariotSolutions))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucVCCzAFxr3o8Dz9w), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-04-09-the-best-typescript-features-you-might-not-be-using.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
