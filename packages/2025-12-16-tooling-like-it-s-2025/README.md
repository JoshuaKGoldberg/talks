# Tooling Like It's 2025

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/raw/main/2025-12-16-tooling-like-it-s-2025.pptx)**

Slides for Tooling Like It's 2025, a talk given at:

- [NodeTLV 2025](https://www.nodetlv.com), Tel Aviv, Israel: December 16, 2025

> These slides were converted from [their original PowerPoint file](https://joshypoomcswaggins-my.sharepoint.com/:p:/g/personal/joshgoldberg_joshypoomcswaggins_onmicrosoft_com/IQDAah3SqTTGTp03wNZsbPTwAVmqg2cNahY3I4u1zmQgjro?e=A0w1CG), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
