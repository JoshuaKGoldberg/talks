# Type-Safe Style Systems: The Future of CSS

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [React India 2023](https://www.reactindia.io/speakers/josh-goldberg-2023), Online: October 3, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://www.youtube.com/watch?v=XDw2yr0KqzQ&ab_channel=ReactIndia))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuJo5Ff6J4u5RFi2qA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-10-03-type-safe-style-systems-the-future-of-css.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
