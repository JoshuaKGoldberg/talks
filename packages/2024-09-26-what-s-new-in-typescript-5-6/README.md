> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EfUc1cvPrJkggNa7sw8AAAABSooZOzfQXAiXc3INFa6XKw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
