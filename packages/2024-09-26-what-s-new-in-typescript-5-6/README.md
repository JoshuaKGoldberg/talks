# What's New in TypeScript 5.6

Slides for What's New in TypeScript 5.6, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-ts-club-vi-return-of-the-squiggle-tickets-1014606444187), Boston, USA: September 26, 2024

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EfUc1cvPrJkggNa7sw8AAAABSooZOzfQXAiXc3INFa6XKw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-09-26-what-s-new-in-typescript-5-6.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
