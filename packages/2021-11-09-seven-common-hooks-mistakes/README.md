# Seven Common Hooks Mistakes

Slides for Seven Common Hooks Mistakes, a talk given at:

- [React Global Online Summit 2021](https://geekle.us/schedule/react3): November 9, 2021 ([repository](https://github.com/JoshuaKGoldberg/seven-common-hooks-mistakes), [video](https://youtu.be/0HhWIvPhbu0?t=21880))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtIeeDEoKBSgLYpetA?e=M5eAct), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
