# Seven Common Hooks Mistakes

Slides for Seven Common Hooks Mistakes, a talk given at:

- [React Global Online Summit 2021](https://geekle.us/schedule/react3): November 9, 2021 ([repository](https://github.com/JoshuaKGoldberg/seven-common-hooks-mistakes), [video](https://youtu.be/0HhWIvPhbu0?t=21880))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtIeeDEoKBSgLYpetA?e=M5eAct), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-11-09-seven-common-hooks-mistakes.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
