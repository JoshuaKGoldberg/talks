# Type System Game Engines

Slides for Type System Game Engines, a talk given at:

- [TSConf 2020](https://tsconf.io/2020/speakers): October 9, 2020 ([blog](https://joshuakgoldberg.com/blog/type-system-game-engines), [video](https://www.youtube.com/watch?v=7nj3vgZjL0Y))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEWI5Fd_5Va4n3ggg?e=XnppFL), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2020-10-09-type-system-game-engines.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
