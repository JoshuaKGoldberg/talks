# Type System Game Engines

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/files/raw/main/2020-10-09-type-system-game-engines.pptx)**

Slides for Type System Game Engines, a talk given at:

- [TSConf 2020](https://tsconf.io/2020/speakers): October 9, 2020 ([blog](https://joshuakgoldberg.com/blog/type-system-game-engines), [video](https://www.youtube.com/watch?v=7nj3vgZjL0Y))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEWI5Fd_5Va4n3ggg?e=XnppFL), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
