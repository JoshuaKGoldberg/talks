# Floating and Sinking Promises: Understanding Broken Async Code

Slides for Floating and Sinking Promises: Understanding Broken Async Code, a talk given at:

- [KCDC 2023](https://www.kcdc.info), Kansas City, USA: June 23, 2023 ([repo](https://github.com/JoshuaKGoldberg/understanding-floating-and-sinking-promises))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt92381lRk5ZuHm2dw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-06-23-floating-and-sinking-promises-understanding-broken-async-code.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
