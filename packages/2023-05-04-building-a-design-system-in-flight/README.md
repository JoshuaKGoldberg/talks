# Building a Design System In-Flight

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/files/raw/main/2023-05-04-building-a-design-system-in-flight.pptx)**

Slides for Building a Design System In-Flight, a talk given at:

- [Stir Trek 2023](https://stirtrek.com/speakers/2023/Josh-Goldberg.html), Columbus, Ohio, USA: May 4, 2023 ([video](https://www.youtube.com/watch?v=rN6kOPUEicE))

> These slides were converted from their original PowerPoint file, so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
