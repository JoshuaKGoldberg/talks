# TypeScript for JavaScripties

Slides for TypeScript for JavaScripties, a talk given at:

- [CityJS Athens 2023](https://greece.cityjsconf.org), Athens, Greece: May 30, 2023 ([video](https://www.youtube.com/watch?v=Bxozlpc1hH8))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt5Xbqy62vlssO23Ew), so they may look a little different.

## Usage

To build the deck into `lib/2023-05-30-typescript-for-javascripties.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
