# TypeScript for JavaScripties

Slides for TypeScript for JavaScripties, a talk given at:

- [CityJS Athens 2023](https://greece.cityjsconf.org), Athens, Greece: May 30, 2023 ([video](https://www.youtube.com/watch?v=Bxozlpc1hH8))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt5Xbqy62vlssO23Ew), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-05-30-typescript-for-javascripties.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
