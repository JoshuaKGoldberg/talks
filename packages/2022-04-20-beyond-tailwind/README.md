# Beyond Tailwind

Slides for Beyond Tailwind, a talk given at:

- [React Global Online Summit 2022](https://geekle.us/schedule/react2): April 20, 2022

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMqAvbgVF1kBMmFWQ?e=8F0qjh), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-04-20-beyond-tailwind.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
