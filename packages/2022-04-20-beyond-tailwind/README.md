# Beyond Tailwind

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/files/raw/main/2022-04-20-beyond-tailwind.pptx)**

Slides for Beyond Tailwind, a talk given at:

- [React Global Online Summit 2022](https://geekle.us/schedule/react2): April 20, 2022

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMqAvbgVF1kBMmFWQ?e=8F0qjh), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
