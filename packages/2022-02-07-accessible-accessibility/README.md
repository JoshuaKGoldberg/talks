# Accessible Accessibility

Slides for Accessible Accessibility, a talk given at:

- DeveloperWeek 2022: February 7, 2022

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtJ7PdIicvSmM5PqYg?e=wa5WCD), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-02-07-accessible-accessibility.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
