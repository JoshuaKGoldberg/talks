# TypeScript Static Analysis Hidden Gems

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2022-10-30-typescript-static-analysis-hidden-gems.pptx)**

Slides for TypeScript Static Analysis Hidden Gems, a talk given at:

- [All Things Open 2022](https://2022.allthingsopen.org/sessions/typescript-static-analysis-hidden-gems), Raleigh, USA: October 30, 2022 ([repo](https://github.com/JoshuaKGoldberg/typescript-static-analysis-hidden-gems))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRH7pSjEMV1rrpTqQ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
