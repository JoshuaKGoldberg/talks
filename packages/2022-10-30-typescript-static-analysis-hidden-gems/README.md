# TypeScript Static Analysis Hidden Gems

Slides for TypeScript Static Analysis Hidden Gems, a talk given at:

- [All Things Open 2022](https://2022.allthingsopen.org/sessions/typescript-static-analysis-hidden-gems), Raleigh, USA: October 30, 2022 ([repo](https://github.com/JoshuaKGoldberg/typescript-static-analysis-hidden-gems))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRH7pSjEMV1rrpTqQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-10-30-typescript-static-analysis-hidden-gems.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
