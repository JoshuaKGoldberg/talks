NumberIfDefined is a type that takes in an existing type, known as a ‘generic’ or ‘template’, and creates a new type based on it.
The ‘extends’ clause makes it a conditional type: it tells the type system that the new type will be one of two possible types, based on whether the left hand side (T) could possibly be the right hand side (undefined).
If T can be undefined, which in this case is true for both ‘undefined’ and ‘string | undefined’, then the new type is ‘number | undefined’.
If T cannot be undefined, which in this case is true only for ‘string’, then the new type is only ‘number’.
