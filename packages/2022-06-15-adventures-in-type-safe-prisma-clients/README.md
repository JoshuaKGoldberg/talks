# Adventures in Type Safe Prisma Clients

Slides for Adventures in Type Safe Prisma Clients, a talk given at:

- [Prisma Day 2022](https://www.prisma.io/day), Berlin, Germany: June 15, 2022 ([video](https://www.youtube.com/watch?v=uFj4qsyGvH0&ab_channel=Prisma))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQLoqKbcgSfwfAZYw?e=fR6JqZ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
