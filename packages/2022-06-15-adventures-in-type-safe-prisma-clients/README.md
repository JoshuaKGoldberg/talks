# Adventures in Type Safe Prisma Clients

Slides for Adventures in Type Safe Prisma Clients, a talk given at:

- [Prisma Day 2022](https://www.prisma.io/day), Berlin, Germany: June 15, 2022 ([video](https://www.youtube.com/watch?v=uFj4qsyGvH0&ab_channel=Prisma))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQLoqKbcgSfwfAZYw?e=fR6JqZ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-06-15-adventures-in-type-safe-prisma-clients.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
