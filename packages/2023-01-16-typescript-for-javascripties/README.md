# TypeScript for JavaScripties

Slides for TypeScript for JavaScripties, a workshop given at:

- [THAT Conf Texas 2023](https://that.us/activities/tNRz6cMoBc0pqJsIFzkC), Round Rock, USA: January 16, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRtHW5HQDcBV3ZVJw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-01-16-typescript-for-javascripties.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
