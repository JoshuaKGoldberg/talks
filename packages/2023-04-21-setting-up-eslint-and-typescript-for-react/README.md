# Setting Up ESLint and TypeScript for React

Slides for Setting Up ESLint and TypeScript for React, a talk given at:

- [React Miami 2023](https://www.reactmiami.com/speakers/joshuagoldberg), Miami, USA: April 21, 2023 ([video](https://www.youtube.com/live/mPPZ-NUnR-4?feature=share&t=25743))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt0cjx-_PLIwDIzclw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
