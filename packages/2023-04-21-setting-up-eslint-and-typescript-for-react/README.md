# Setting Up ESLint and TypeScript for React

Slides for Setting Up ESLint and TypeScript for React, a talk given at:

- [React Miami 2023](https://www.reactmiami.com/speakers/joshuagoldberg), Miami, USA: April 21, 2023 ([video](https://www.youtube.com/live/mPPZ-NUnR-4?feature=share&t=25743))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt0cjx-_PLIwDIzclw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-04-21-setting-up-eslint-and-typescript-for-react.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
