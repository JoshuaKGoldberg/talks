# Converting a Game Engine to TypeScript

Slides for Converting a Game Engine to TypeScript, a talk given at:

- [TSConf 2021](https://tsconf.io/2021): September 10, 2021 ([video](https://www.youtube.com/watch?v=xTpRPGqiSUY))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtF61-wTnqOSTx3QNA?e=xzAuNg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-09-10-converting-a-game-engine-to-typescript.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
