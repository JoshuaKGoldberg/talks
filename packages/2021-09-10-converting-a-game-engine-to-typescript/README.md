# Converting a Game Engine to TypeScript

Slides for Converting a Game Engine to TypeScript, a talk given at:

- [TSConf 2021](https://tsconf.io/2021): September 10, 2021 ([video](https://www.youtube.com/watch?v=xTpRPGqiSUY))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtF61-wTnqOSTx3QNA?e=xzAuNg), so they may look a little different.

## Usage

To build the deck into `lib/2021-09-10-converting-a-game-engine-to-typescript.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
