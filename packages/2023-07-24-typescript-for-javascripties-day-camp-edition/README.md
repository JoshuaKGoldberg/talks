# TypeScript for Javascripties: Day Camp Edition

Slides for TypeScript for Javascripties: Day Camp Edition, a talk given at:

- [THAT Conf WI 2023](https://that.us/activities/N9IlPoBi4vV2dukgVw8U), Wisconsin Dells, USA: July 24, 2023

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuEPyh8LP9z8JcM-xQ), so they may look a little different.

## Usage

To build the deck into `lib/2023-07-24-typescript-for-javascripties-day-camp-edition.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
