# TypeScript for Javascripties: Day Camp Edition

Slides for TypeScript for Javascripties: Day Camp Edition, a talk given at:

- [THAT Conf WI 2023](https://that.us/activities/N9IlPoBi4vV2dukgVw8U), Wisconsin Dells, USA: July 24, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuEPyh8LP9z8JcM-xQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-07-24-typescript-for-javascripties-day-camp-edition.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
