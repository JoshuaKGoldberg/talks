# TypeScript Generics: Practical Fun

Slides for TypeScript Generics: Practical Fun, a talk given at:

- [JetBrains JavaScript Day 2024](https://lp.jetbrains.com/javascript-day-2024), Online: October 24, 2024 ([video](https://www.youtube.com/live/Uf1B1dTLRXs))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuc_Q-_DJaamt8GvsA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-10-24-typescript-generics-practical-fun.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
