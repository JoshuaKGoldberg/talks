# TypeScript Generics: Practical Fun

Slides for TypeScript Generics: Practical Fun, a talk given at:

- [JetBrains JavaScript Day 2024](https://lp.jetbrains.com/javascript-day-2024), Online: October 24, 2024 ([video](https://www.youtube.com/live/Uf1B1dTLRXs))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuc_Q-_DJaamt8GvsA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
