# From Takedown to TypeScript

Slides for From Takedown to TypeScript, a talk given at:

- CascadiaJS 2021: November 3, 2021 ([video](https://www.youtube.com/watch?v=UhUFW-sYJwk))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtIT0PxybT6NjP2dWw?e=iNbYbv), so they may look a little different.

## Usage

To build the deck into `lib/2021-11-03-from-takedown-to-typescript.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
