# From Takedown to TypeScript

Slides for From Takedown to TypeScript, a talk given at:

- CascadiaJS 2021: November 3, 2021 ([video](https://www.youtube.com/watch?v=UhUFW-sYJwk))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtIT0PxybT6NjP2dWw?e=iNbYbv), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-11-03-from-takedown-to-typescript.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
