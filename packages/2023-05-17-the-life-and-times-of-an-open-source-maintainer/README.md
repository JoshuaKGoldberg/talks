# The Life and Times of an Open Source Maintainer

Slides for The Life and Times of an Open Source Maintainer, a talk given at:

- [PhillyJS](https://www.eventbrite.com/e/philadelphia-javascript-club-contributing-to-open-source-projects-tickets-621853449407), Philadelphia, USA: May 17, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt4oE1oTyST7IfyJhg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-05-17-the-life-and-times-of-an-open-source-maintainer.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
