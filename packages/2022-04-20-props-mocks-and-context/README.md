# Props, Mocks, and Context

Slides for Props, Mocks, and Context, a talk given at:

- [React Global Online Summit 2022](https://geekle.us/schedule/react2): April 20, 2022 ([repo](https://github.com/JoshuaKGoldberg/props-mocks-and-context-talk), [video](https://youtu.be/u4QTr56t7iM?t=21124))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMop28KDmFo0iZApg?e=L0FzQ2), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
