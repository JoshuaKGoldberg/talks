# Props, Mocks, and Context

Slides for Props, Mocks, and Context, a talk given at:

- [React Global Online Summit 2022](https://geekle.us/schedule/react2): April 20, 2022 ([repo](https://github.com/JoshuaKGoldberg/props-mocks-and-context-talk), [video](https://youtu.be/u4QTr56t7iM?t=21124))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMop28KDmFo0iZApg?e=L0FzQ2), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-04-20-props-mocks-and-context.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
