# Deep TypeScript Tips and Tricks

Slides for Deep TypeScript Tips and Tricks, a workshop given at:

- [Node Congress 2024](https://portal.gitnation.org/contents/deep-typescript-tips-and-tricks), Online: April 8, 2024 ([repo](https://github.com/JoshuaKGoldberg/deep-typescript-tips-and-tricks))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucR9JEAF12RCpXGNw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-04-08-deep-typescript-tips-and-tricks.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
