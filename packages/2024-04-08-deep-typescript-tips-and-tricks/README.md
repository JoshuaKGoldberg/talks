# Deep TypeScript Tips and Tricks

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/files/raw/main/2024-04-08-deep-typescript-tips-and-tricks.pptx)**

Slides for Deep TypeScript Tips and Tricks, a workshop given at:

- [Node Congress 2024](https://portal.gitnation.org/contents/deep-typescript-tips-and-tricks), Online: April 8, 2024 ([repo](https://github.com/JoshuaKGoldberg/deep-typescript-tips-and-tricks))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucR9JEAF12RCpXGNw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
