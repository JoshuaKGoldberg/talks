# TypeScript and Aspire

Slides for TypeScript and Aspire, a talk given at:

- [AspireConf 2026](https://aspire.dev/aspireconf), Online: March 23, 2026

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/IQBDHbuSZn3gRZ_IOZy85E17ATWFM6BakQDbxnLWXwvh3iM), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2026-03-23-typescript-and-aspire.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
