# TypeScript and Aspire

Slides for TypeScript and Aspire, a talk given at:

- [AspireConf 2026](https://aspire.dev/aspireconf), Online: March 23, 2026

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/IQBDHbuSZn3gRZ_IOZy85E17ATWFM6BakQDbxnLWXwvh3iM), so they may look a little different.

## Usage

To build the deck into `lib/2026-03-23-typescript-and-aspire.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
