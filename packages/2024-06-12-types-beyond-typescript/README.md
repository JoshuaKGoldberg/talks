# Types Beyond TypeScript

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/raw/main/2024-06-12-types-beyond-typescript.pptx)**

Slides for Types Beyond TypeScript, a talk given at:

- [React Summit 2024](https://reactsummit.com), Amsterdam, NL: June 12, 2024 ([video](https://gitnation.com/contents/types-beyond-typescript))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucs8iTt_07z09exqA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
