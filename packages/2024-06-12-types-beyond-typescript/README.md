# Types Beyond TypeScript

Slides for Types Beyond TypeScript, a talk given at:

- [React Summit 2024](https://reactsummit.com), Amsterdam, NL: June 12, 2024 ([video](https://gitnation.com/contents/types-beyond-typescript))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucs8iTt_07z09exqA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-06-12-types-beyond-typescript.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
