# Super Strength ESLint

Slides for Super Strength ESLint, a talk given at:

- [JS Poland 2020](https://js-poland.pl): November 20, 2020 ([video](https://www.youtube.com/watch?v=H4FL1hZj2S8))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEiyt1HUAbfhU10Yw?e=erd8j7), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2020-11-20-super-strength-eslint.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
