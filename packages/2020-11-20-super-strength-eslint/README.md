# Super Strength ESLint

Slides for Super Strength ESLint, a talk given at:

- [JS Poland 2020](https://js-poland.pl): November 20, 2020 ([video](https://www.youtube.com/watch?v=H4FL1hZj2S8))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEiyt1HUAbfhU10Yw?e=erd8j7), so they may look a little different.

## Usage

To build the deck into `lib/2020-11-20-super-strength-eslint.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
