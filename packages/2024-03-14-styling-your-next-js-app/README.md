# Styling your Next.js App

Slides for Styling your Next.js App, a talk given at:

- [PhillyJS](https://www.eventbrite.com/e/philadelphia-js-club-style-authenticate-your-nextjs-app-w-josh-joe-tickets-828968245337), Philadelphia, USA: March 14, 2024

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucNMmuanjYjn_XUIw), so they may look a little different.

## Usage

To build the deck into `lib/2024-03-14-styling-your-next-js-app.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
