# Styling your Next.js App

Slides for Styling your Next.js App, a talk given at:

- [PhillyJS](https://www.eventbrite.com/e/philadelphia-js-club-style-authenticate-your-nextjs-app-w-josh-joe-tickets-828968245337), Philadelphia, USA: March 14, 2024

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvucNMmuanjYjn_XUIw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-03-14-styling-your-next-js-app.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
