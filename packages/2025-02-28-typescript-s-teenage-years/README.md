# TypeScript's Teenage Years

Slides for TypeScript's Teenage Years, a talk given at:

- [Paris TypeScript la Conf'](https://la-conf.typescript.paris), Paris, France: February 28, 2025

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/Eank6JDG2JtIjbvKUlp47pkBad5tfRGj9CwOJJ44-m8xww), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2025-02-28-typescript-s-teenage-years.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
