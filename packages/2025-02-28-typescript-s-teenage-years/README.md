# TypeScript's Teenage Years

Slides for TypeScript's Teenage Years, a talk given at:

- [Paris TypeScript la Conf'](https://la-conf.typescript.paris), Paris, France: February 28, 2025

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/Eank6JDG2JtIjbvKUlp47pkBad5tfRGj9CwOJJ44-m8xww), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
