# Microfrontends at Scale

Slides for Microfrontends at Scale, a talk given at:

- [WeAreDevelopers World Congress 2021](https://app.swapcard.com/event/wearedevelopers-world-congress/planning/UGxhbm5pbmdfNTU2ODI1): June 28, 2021 ([video](https://app.swapcard.com/event/wearedevelopers-world-congress/planning/UGxhbm5pbmdfNTU2ODI1))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFjcGsr46JzTI5-zQ?e=3cqHXt), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-06-28-microfrontends-at-scale.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
