# Microfrontends at Scale

Slides for Microfrontends at Scale, a talk given at:

- [WeAreDevelopers World Congress 2021](https://app.swapcard.com/event/wearedevelopers-world-congress/planning/UGxhbm5pbmdfNTU2ODI1): June 28, 2021 ([video](https://app.swapcard.com/event/wearedevelopers-world-congress/planning/UGxhbm5pbmdfNTU2ODI1))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFjcGsr46JzTI5-zQ?e=3cqHXt), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
