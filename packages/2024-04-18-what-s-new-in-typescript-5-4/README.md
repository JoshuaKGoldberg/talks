Slides for What's New in TypeScript 5.4, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-typescript-meetup-the-first-one-ever-tickets-858516595247), Boston, USA: April 18, 2024

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EfUc1cvPrJkggNadsw8AAAABF7EL0IhTnbNca5RIab61qQ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
