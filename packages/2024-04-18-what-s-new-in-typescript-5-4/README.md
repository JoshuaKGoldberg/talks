# What's New in TypeScript 5.4

Slides for What's New in TypeScript 5.4, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-typescript-meetup-the-first-one-ever-tickets-858516595247), Boston, USA: April 18, 2024

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EfUc1cvPrJkggNadsw8AAAABF7EL0IhTnbNca5RIab61qQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-04-18-what-s-new-in-typescript-5-4.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
