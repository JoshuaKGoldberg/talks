# How to Learn to Love the Linter

Slides for How to Learn to Love the Linter, a talk given at:

- [Boston Code Camp 40](https://www.bostoncodecamp.com/CC40/Sessions), Boston, USA: March 28, 2026

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/IQCDmSvMrSo4QYFv6ue2TinVAaxRaRBZz2FJ8LXR0jHmzts), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2026-03-28-how-to-learn-to-love-the-linter.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
