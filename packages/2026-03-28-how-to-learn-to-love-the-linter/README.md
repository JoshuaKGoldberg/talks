# How to Learn to Love the Linter

Slides for How to Learn to Love the Linter, a talk given at:

- [Boston Code Camp 40](https://www.bostoncodecamp.com/CC40/Sessions), Boston, USA: March 28, 2026

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/IQCDmSvMrSo4QYFv6ue2TinVAaxRaRBZz2FJ8LXR0jHmzts), so they may look a little different.

## Usage

To build the deck into `lib/2026-03-28-how-to-learn-to-love-the-linter.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
