Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [revo.js 2023](https://revojs.ro/2023), Timișoara, Romania: October 5, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://www.youtube.com/watch?v=XMn9JnPH9ic&ab_channel=tim.js))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMcCHoud4DwsLktrw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
