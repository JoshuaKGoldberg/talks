# Type-Safe Style Systems: The Future of CSS

Slides for Type-Safe Style Systems: The Future of CSS, a talk given at:

- [revo.js 2023](https://revojs.ro/2023), Timișoara, Romania: October 5, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-safe-style-systems), [video](https://www.youtube.com/watch?v=XMn9JnPH9ic&ab_channel=tim.js))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMcCHoud4DwsLktrw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-10-05-type-safe-style-systems-the-future-of-css.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
