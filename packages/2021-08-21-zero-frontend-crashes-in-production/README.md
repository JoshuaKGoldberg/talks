# "Zero" Frontend Crashes in Production

Slides for "Zero" Frontend Crashes in Production, a talk given at:

- Reliable Web Summit 2021: August 21, 2021 ([video](https://www.youtube.com/watch?v=dfLa5DWZdbY&t=41s&ab_channel=ng-conf))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtF3JLBcCyJSXhJABQ?e=6Xxnht), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-08-21-zero-frontend-crashes-in-production.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
