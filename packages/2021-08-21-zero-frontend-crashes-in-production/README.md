Slides for "Zero" Frontend Crashes in Production, a talk given at:

- Reliable Web Summit 2021: August 21, 2021 ([video](https://www.youtube.com/watch?v=dfLa5DWZdbY&t=41s&ab_channel=ng-conf))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtF3JLBcCyJSXhJABQ?e=6Xxnht), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
