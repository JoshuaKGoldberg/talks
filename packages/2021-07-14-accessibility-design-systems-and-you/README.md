# Accessibility, Design Systems, and YOU!

Slides for Accessibility, Design Systems, and YOU!, a talk given at:

- [CSSCamp 2021](https://csscamp.tech/speakers/2021/josh-goldberg): July 14, 2021 ([video](https://www.youtube.com/watch?v=gbNPXvfDAik))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFnhBSaIhabdMf7oQ?e=0Me4QN), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
