# Accessibility, Design Systems, and YOU!

Slides for Accessibility, Design Systems, and YOU!, a talk given at:

- [CSSCamp 2021](https://csscamp.tech/speakers/2021/josh-goldberg): July 14, 2021 ([video](https://www.youtube.com/watch?v=gbNPXvfDAik))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFnhBSaIhabdMf7oQ?e=0Me4QN), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-07-14-accessibility-design-systems-and-you.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
