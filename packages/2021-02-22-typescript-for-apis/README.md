# TypeScript for APIs

Slides for TypeScript for APIs, a talk given at:

- [JSWorld 2021](https://2021.frontenddeveloperlove.com): February 22, 2021 ([video](https://www.youtube.com/watch?v=b40w2H5kKEk))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEsA38Jz-H_4zp25g?e=wSxDeT), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-02-22-typescript-for-apis.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
