# TypeScript for APIs

Slides for TypeScript for APIs, a talk given at:

- [JSWorld 2021](https://2021.frontenddeveloperlove.com): February 22, 2021 ([video](https://www.youtube.com/watch?v=b40w2H5kKEk))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtEsA38Jz-H_4zp25g?e=wSxDeT), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
