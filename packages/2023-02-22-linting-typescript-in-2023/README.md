# Linting TypeScript in 2023

Slides for Linting TypeScript in 2023, a talk given at:

- [Wrocław TypeScript](https://www.meetup.com/wroctypescript/events/290894011), Online: February 22, 2023 ([repo](https://github.com/JoshuaKGoldberg/linting-typescript-in-2023), [video](https://www.youtube.com/watch?v=fjPzlywUH0M&ab_channel=Wroc%C5%82awTypeScript))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtxkNY3xH62eTrZpDQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-02-22-linting-typescript-in-2023.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
