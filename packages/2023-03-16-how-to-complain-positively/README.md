# How to Complain Positively

Slides for How to Complain Positively, a talk given at:

- [StaffPlus NYC 2023](https://leaddev.com/staffplus-new-york23/agenda), New York City, USA: March 16, 2023 ([video](https://leaddev.com/new-york/staffplus/video/2023/how-complain-positively))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtxmfY5e0vvS62B62A), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-03-16-how-to-complain-positively.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
