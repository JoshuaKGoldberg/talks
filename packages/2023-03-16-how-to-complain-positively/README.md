- [StaffPlus NYC 2023](https://leaddev.com/staffplus-new-york23/agenda), New York City, USA: March 16, 2023 ([video](https://leaddev.com/new-york/staffplus/video/2023/how-complain-positively))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtxmfY5e0vvS62B62A), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
