# WebXR Karaoke

Slides for WebXR Karaoke, a talk given at:

- [React Brussels 2022](https://react.brussels), Brussels, Belgium: October 14, 2022 ([repo](https://github.com/karaokenite/karaokenite-react), [video](https://www.youtube.com/watch?v=W7YIQ5qkrok))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQ-v1RPuPSQg0LZRA), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-10-14-webxr-karaoke.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
