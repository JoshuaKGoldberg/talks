# WebXR Karaoke

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/raw/main/2022-10-14-webxr-karaoke.pptx)**

Slides for WebXR Karaoke, a talk given at:

- [React Brussels 2022](https://react.brussels), Brussels, Belgium: October 14, 2022 ([repo](https://github.com/karaokenite/karaokenite-react), [video](https://www.youtube.com/watch?v=W7YIQ5qkrok))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtQ-v1RPuPSQg0LZRA), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
