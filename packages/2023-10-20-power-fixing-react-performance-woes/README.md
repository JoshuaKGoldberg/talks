# Power Fixing React Performance Woes

Slides for Power Fixing React Performance Woes, a talk given at:

- [React Advanced 2023](https://reactadvanced.com), Online: October 20, 2023 ([video](https://portal.gitnation.org/contents/power-fixing-react-performance-woes))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMY-qq2DHH_aGBZ4w), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-10-20-power-fixing-react-performance-woes.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
