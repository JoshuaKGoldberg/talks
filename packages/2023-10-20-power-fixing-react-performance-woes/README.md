Slides for Power Fixing React Performance Woes, a talk given at:

- [React Advanced 2023](https://reactadvanced.com), Online: October 20, 2023 ([video](https://portal.gitnation.org/contents/power-fixing-react-performance-woes))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuMY-qq2DHH_aGBZ4w), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
