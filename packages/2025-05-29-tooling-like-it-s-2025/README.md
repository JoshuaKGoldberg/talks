# Tooling Like It's 2025

Slides for Tooling Like It's 2025, a talk given at:

- [JSHeroes 2025](https://jsheroes.io), Cluj-Napoca, Romania: May 29, 2025 ([video](https://youtu.be/p-J9b4oq-sY?si=SmdRiqwjLJlUG7MD))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EVUYxf_tAeRDnO6VLlEBC4cBuuQMKjwImZLx4jhLqTISVQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2025-05-29-tooling-like-it-s-2025.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
