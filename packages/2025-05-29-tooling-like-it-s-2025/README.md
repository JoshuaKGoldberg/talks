# Tooling Like It's 2025

Slides for Tooling Like It's 2025, a talk given at:

- [JSHeroes 2025](https://jsheroes.io), Cluj-Napoca, Romania: May 29, 2025 ([video](https://youtu.be/p-J9b4oq-sY?si=SmdRiqwjLJlUG7MD))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EVUYxf_tAeRDnO6VLlEBC4cBuuQMKjwImZLx4jhLqTISVQ), so they may look a little different.

## Usage

To build the deck into `lib/2025-05-29-tooling-like-it-s-2025.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
