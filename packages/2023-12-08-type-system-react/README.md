# Type System React

Slides for Type System React, a talk given at:

- [React Day Berlin 2023](https://reactday.berlin), Online: December 8, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-system-react), [video](https://portal.gitnation.org/contents/type-system-react))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQNfsGTs7ru1I3Axw), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
