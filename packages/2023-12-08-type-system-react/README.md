# Type System React

Slides for Type System React, a talk given at:

- [React Day Berlin 2023](https://reactday.berlin), Online: December 8, 2023 ([repo](https://github.com/JoshuaKGoldberg/type-system-react), [video](https://portal.gitnation.org/contents/type-system-react))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQNfsGTs7ru1I3Axw), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-12-08-type-system-react.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
