# Static Analysis: Don't Fear the Linter

> **[Download the built PowerPoint file](https://github.com/JoshuaKGoldberg/talk-files/blob/main/2023-06-22-static-analysis-don-t-fear-the-linter.pptx)**

Slides for Static Analysis: Don't Fear the Linter, a talk given at:

- [KCDC 2023](https://www.kcdc.info), Kansas City, USA: June 22, 2023

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt90PBRDuBcngQYCPg), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
