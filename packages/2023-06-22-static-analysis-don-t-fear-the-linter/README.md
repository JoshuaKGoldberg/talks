# Static Analysis: Don't Fear the Linter

Slides for Static Analysis: Don't Fear the Linter, a talk given at:

- [KCDC 2023](https://www.kcdc.info), Kansas City, USA: June 22, 2023

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvt90PBRDuBcngQYCPg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-06-22-static-analysis-don-t-fear-the-linter.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
