# What's New in TypeScript 6.0

Slides for What's New in TypeScript 6.0, a talk given at:

- [Boston TS Club](https://www.eventbrite.com/e/boston-typescript-club-may-tickets-1987954208552), Boston, USA: May 21, 2026

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/IQCCygPYtjc9QZ3OY-hQkA9xAXku1klEg2CQy-LQ8Dbjnfk), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2026-05-21-what-s-new-in-typescript-6-0.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
