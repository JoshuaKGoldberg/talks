# Demystifying GraphQL Typings Generation

Slides for Demystifying GraphQL Typings Generation, a talk given at:

- Untangling GraphQL 2022: April 6, 2022 ([repo 1](https://github.com/JoshuaKGoldberg/graphql-typings-generation), [repo 2](https://github.com/JoshuaKGoldberg/a-lovely-graphql-server), [video](https://www.youtube.com/watch?v=1yxFeXXqEDY&ab_channel=NearForm))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtMkNiknbpwMPMDC7A?e=cIRVur), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2022-04-06-demystifying-graphql-typings-generation.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
