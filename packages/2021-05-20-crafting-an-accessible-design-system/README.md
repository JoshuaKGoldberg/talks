# Crafting an Accessible Design System

Slides for Crafting an Accessible Design System, a talk given at:

- [A11y Bytes 2021](https://a11ybytes.org): May 20, 2021 ([video](https://www.youtube.com/watch?v=r4EHdAXXqpg))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFXY_iRtSgSUDV8Qg?e=7g1Hro), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-05-20-crafting-an-accessible-design-system.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
