# Crafting an Accessible Design System

Slides for Crafting an Accessible Design System, a talk given at:

- [A11y Bytes 2021](https://a11ybytes.org): May 20, 2021 ([video](https://www.youtube.com/watch?v=r4EHdAXXqpg))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFXY_iRtSgSUDV8Qg?e=7g1Hro), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
