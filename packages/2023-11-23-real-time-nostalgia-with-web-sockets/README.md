# Real Time Nostalgia with Web Sockets

Slides for Real Time Nostalgia with Web Sockets, a talk given at:

- [Wey Wey Web 2023](https://www.weyweyweb.com), Malaga, Spain: November 23, 2023 ([video](https://www.youtube.com/watch?v=uGdUSS4NA_4&ab_channel=WeyWeyWeb))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQPSA8YafPNO7NHLg), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
