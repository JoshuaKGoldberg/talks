# Real Time Nostalgia with Web Sockets

Slides for Real Time Nostalgia with Web Sockets, a talk given at:

- [Wey Wey Web 2023](https://www.weyweyweb.com), Malaga, Spain: November 23, 2023 ([video](https://www.youtube.com/watch?v=uGdUSS4NA_4&ab_channel=WeyWeyWeb))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQPSA8YafPNO7NHLg), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-11-23-real-time-nostalgia-with-web-sockets.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
