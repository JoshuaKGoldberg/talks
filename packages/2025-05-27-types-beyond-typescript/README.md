- [JNation 2025](https://jnation.pt), Coimbra, Portugal: May 27, 2025 ([video](https://www.youtube.com/watch?v=XMQwnxXyOF8&list=PLXADOFXCGUmURasW-yOfzhZ9IsDlQiFSk&index=4&ab_channel=JNation))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EaXjXllDAs1LgW4G4If3rnsBbmMXCpgtfbltx__QgAePpQ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
