# Types Beyond TypeScript

Slides for Types Beyond TypeScript, a talk given at:

- [JNation 2025](https://jnation.pt), Coimbra, Portugal: May 27, 2025 ([video](https://www.youtube.com/watch?v=XMQwnxXyOF8&list=PLXADOFXCGUmURasW-yOfzhZ9IsDlQiFSk&index=4&ab_channel=JNation))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/c/d699accfcbd51cf5/EaXjXllDAs1LgW4G4If3rnsBbmMXCpgtfbltx__QgAePpQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2025-05-27-types-beyond-typescript.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
