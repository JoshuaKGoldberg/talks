# Design Systems: Maximum Consistency, Minimum Effort

Slides for Design Systems: Maximum Consistency, Minimum Effort, a talk given at:

- [THAT Conf Texas 2023](https://that.us/activities/tNRz6cMoBc0pqJsIFzkC), Round Rock, USA: January 17, 2023 ([repo](https://github.com/JoshuaKGoldberg/design-system-sketch))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRv5w2TlFXfhHorNQ), so they may look a little different.

## Usage

To build the deck into `lib/2023-01-17-design-systems-maximum-consistency-minimum-effort.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
