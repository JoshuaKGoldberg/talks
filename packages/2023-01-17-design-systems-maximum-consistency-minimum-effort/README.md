# Design Systems: Maximum Consistency, Minimum Effort

Slides for Design Systems: Maximum Consistency, Minimum Effort, a talk given at:

- [THAT Conf Texas 2023](https://that.us/activities/tNRz6cMoBc0pqJsIFzkC), Round Rock, USA: January 17, 2023 ([repo](https://github.com/JoshuaKGoldberg/design-system-sketch))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtRv5w2TlFXfhHorNQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-01-17-design-systems-maximum-consistency-minimum-effort.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
