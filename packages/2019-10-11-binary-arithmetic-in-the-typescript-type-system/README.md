# Binary Arithmetic in the TypeScript Type System

Slides for Binary Arithmetic in the TypeScript Type System, a talk given at:

- [TSConf 2019](https://tsconf.io/2019), Seattle, USA: October 11, 2019 ([blog](https://joshuakgoldberg.com/blog/binary-arithmetic), [video](https://www.youtube.com/watch?v=7lyb22x9tcM))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvqNRDN6yLPZvYTb8KA?e=aNxTrY), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2019-10-11-binary-arithmetic-in-the-typescript-type-system.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
