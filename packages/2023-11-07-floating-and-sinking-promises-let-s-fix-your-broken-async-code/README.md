# Floating and Sinking Promises: Let’s Fix Your Broken Async Code

Slides for Floating and Sinking Promises: Let’s Fix Your Broken Async Code, a workshop given at:

- NodeConf EU 2023, Kilkenny, Ireland: November 7, 2023 ([repo](https://github.com/JoshuaKGoldberg/fixing-floating-and-sinking-promises))

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQL58wf2Pb4AXSyag), so they may look a little different.

## Usage

To build the deck into `lib/2023-11-07-floating-and-sinking-promises-let-s-fix-your-broken-async-code.pptx`:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
