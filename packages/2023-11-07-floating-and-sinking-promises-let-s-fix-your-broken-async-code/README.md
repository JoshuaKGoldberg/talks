# Floating and Sinking Promises: Let’s Fix Your Broken Async Code

Slides for Floating and Sinking Promises: Let’s Fix Your Broken Async Code, a workshop given at:

- NodeConf EU 2023, Kilkenny, Ireland: November 7, 2023 ([repo](https://github.com/JoshuaKGoldberg/fixing-floating-and-sinking-promises))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuQL58wf2Pb4AXSyag), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2023-11-07-floating-and-sinking-promises-let-s-fix-your-broken-async-code.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
