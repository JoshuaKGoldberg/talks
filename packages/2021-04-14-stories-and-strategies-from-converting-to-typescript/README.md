# Stories and Strategies from Converting to TypeScript

Slides for Stories and Strategies from Converting to TypeScript, a talk given at:

- [React Summit 2021](https://portal.gitnation.org/events/react-summit-remote-edition-2021): April 14, 2021 ([video](https://portal.gitnation.org/contents/stories-and-strategies-from-converting-to-typescript))

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvtFPvqJXi-vVGyfgLg?e=Bc7qw5), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2021-04-14-stories-and-strategies-from-converting-to-typescript.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
