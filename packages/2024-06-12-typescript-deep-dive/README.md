# TypeScript Deep Dive

Slides for TypeScript Deep Dive, a workshop given at:

- [React Summit 2024](https://reactsummit.com), Amsterdam, NL: June 12, 2024

## Usage

This deck's source is the [Slidev](https://sli.dev) deck in `src/`.
It was converted from [its original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuczH8bDQeUU4-5HhQ), so it may look a little different.

```shell
pnpm build
```

...writes `lib/2024-06-12-typescript-deep-dive.pptx` with slidev2pptx.

```shell
pnpm dev
```

...presents the deck with Slidev.
