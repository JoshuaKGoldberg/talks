# TypeScript Deep Dive

> **[Download the talk's PowerPoint slides here](https://github.com/JoshuaKGoldberg/talk-files/raw/main/2024-06-12-typescript-deep-dive.pptx)**

Slides for TypeScript Deep Dive, a workshop given at:

- [React Summit 2024](https://reactsummit.com), Amsterdam, NL: June 12, 2024

> These slides were converted from [their original PowerPoint file](https://1drv.ms/p/s!AvUc1cvPrJnWvuczH8bDQeUU4-5HhQ), so they may look a little different.

## Usage

To build the deck into a PowerPoint file in `lib/` with slidev2pptx:

```shell
pnpm build
```

To present it with [Slidev](https://sli.dev):

```shell
pnpm dev
```
